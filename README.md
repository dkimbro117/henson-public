# Henson

Group travel for identity-aware crews. Lived-experience profiles and destination intelligence inform which places rise to the top; Claude writes itineraries, briefs, and Concierge chat from that ground truth — it does not invent the ranking.

> **Source available on request — not open source.** This repository is a portfolio overview of a private product. It does not contain runnable application code. See [LICENSE](LICENSE).

## What it is

- Organizers plan group trips with destination intelligence that stays inspectable: stored scores and lived-experience context, not chat memory.
- Travelers get a participant portal and a Concierge that answers from that same ground truth.
- Domestic trips stay coordination-first; international trips surface more destination intelligence.
